- *Goal*: a sequential Rust crate that rasterizes polygons (coverage and approx paths),
  lines and points onto a lattice grid window and gives the controlledburn sparse tables.
- *Architecture*: ~geo-traits~ input is normalized into a reused buffer. A walker (a
  port of controlledburn ~walk_polyline~) records cell traversals in a flat arena.
  Coverage fractions use exactextract arithmetic. A winding sweep emits runs and edges.
  The approx path is an intercept sweep. All indices are global lattice indices, so an
  orchestrator can split the work by geometry or by grid window.
- *Tech stack*: Rust 1.98.0 (edition 2024), ~geo-traits~ 0.3, ~thiserror~ 2; dev:
  ~geo-types~ 0.7.19, ~wkb~ 0.9.2, ~proptest~, ~criterion~, ~toml~; Python oracle under

* Review Focus

1. A geometry entirely outside the window (left, right, above, below): ~Ok~, no records,
   one ~GeomIndex~ with empty ranges. Pinned in Task 8 (~invariants.rs~
   ~outside_window_gives_no_records~), Task 9 and Task 10.
2. A window of one row or one column (a thin brix chunk): the records equal the full
   burn's records for those cells. Pinned in Task 12 (chunk sizes start at 1).
3. Repeated consecutive vertices in a ring: the same coverage as the cleaned ring.
   Pinned in Task 8 (~regression.rs~ ~repeated_vertices_do_not_change_coverage~).
4. A sliver polygon much thinner than a cell: every edge fraction is in (0, 1), and
   the area is conserved. Pinned in Task 8 (~regression.rs~ ~sliver_fractions_stay_in_range~).
5. Ids that are not in order, and duplicate ids: the output follows the caller's order
   and has one ~GeomIndex~ per input item. Pinned in Task 8 (~invariants.rs~
   ~ids_follow_caller_order~).

#+begin_src markdown
# burnscars

Sparse rasterization of polygons, lines and points onto a regular grid, in Rust.
Polygons get exact per-cell coverage fractions (coverage mode) or the cell-centre
rule (approx mode). Time and memory are O(perimeter): the output is sparse tables,
never a dense raster.

burnscars is a port of the controlledburn C++ core. It has no internal parallelism.
Its grid windows use global lattice indices, so a caller can split the work by
geometry or by grid chunk and run it in parallel.

## Inspiration and credits

- [controlledburn](https://github.com/hypertidy/controlledburn) (Michael Sumner): the
  code that this crate ports; sparse output, the winding sweep, the approx mode.
- [exactextract](https://github.com/isciences/exactextract) (Daniel Baston, ISciences):
  the exact coverage algorithm (cell traversal, crossing, `left_hand_area`); the
  reference for correctness.
- [fasterize](https://github.com/hypertidy/fasterize) (moved from
  `ecohealthalliance/fasterize` in March 2025): the cell-centre rule and the pixel
  functions that approx mode and a later materialize follow.
- [rusterize](https://github.com/ttrotto/rusterize): prior art for scanline
  rasterization in Rust.
- GDAL rasterize: the cell-centre oracle for approx mode (through rasterio).

## Upstream and rules

- Ported from controlledburn `1f8a25fd030ac6ec1aa2fbf2c69ee35df8c17558` and
  exactextract `67969d99d1dfe1115be955087e2c48e1aab133e2`.
- If controlledburn and exactextract disagree, exactextract wins. The oracle suite
  decides.
- No code comes from GEOS or JTS. GEOS is used only as a black-box test oracle
  (shapely, in `oracle/`).

## Output

Four tables in struct-of-arrays form: `runs` (interior intervals), `edges` (boundary
cells with a coverage fraction), `lines` (length in cell), `points`. Indices are
global, 0-based lattice indices; `col_end` is exclusive. See the crate docs for the
relation to CSR and CSC sparse matrices.

## Development

`just` lists the tasks. `just ci` runs format, lint, tests and doctests.
`just oracle` regenerates the oracle fixtures (needs `uv`).

//! Sparse rasterization of polygons, lines and points onto a regular grid.
//!
//! A port of the controlledburn core (Apache-2.0, Copyright 2025 Michael Sumner),
//! commit 1f8a25fd030ac6ec1aa2fbf2c69ee35df8c17558, with the exact coverage arithmetic
//! of exactextract (Apache-2.0, Copyright 2018-2022 ISciences, LLC),
//! commit 67969d99d1dfe1115be955087e2c48e1aab133e2.
//!
//! # Output as a sparse matrix
//!
//! The polygon output is the sparse coverage matrix `A[cell, geometry]`. The value is
//! the fraction of the cell that the geometry covers, and it is 1 for interior cells.
//! Zonal statistics are `(Aᵀv) / (Aᵀ1)` for a raster `v`. This is what exactextract
//! computes.
//!
//! - `runs` is a run-length layer: each entry is one interval of columns in one row,
//!   all with the value 1 ("RLE-CSR"). Plain CSR stores one entry per cell, which is
//!   O(area). The runs keep the storage at O(perimeter).
//! - `edges` is COO: explicit `(row, col, value)` triples.
//! - The burn order is geometry-major, so `geom_ptr` is a CSC index with the geometry
//!   as the column.
//! - `to_row_major()` builds the CSR index (`row_ptr`).
//! - Two geometries can cover the same cell, so the full object is a sparse
//!   `(row, col, id)` tensor. One geometry has at most one record per cell.
#+end_src

#+begin_src rust
//! Lattice, grid window and index types.
//!
//! Index rules follow exactextract (Apache-2.0, Copyright 2018-2022 ISciences, LLC),
//! commit 67969d99d1dfe1115be955087e2c48e1aab133e2: `src/grid.h` (`Grid::get_column`,
//! `Grid::get_row`). Cell edges come from the lattice origin, not from a window corner.

use std::fmt;
use std::ops::Range;

/// Global lattice row. Row 0 is at the top.
#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub struct Row(pub u32);

/// Global lattice column.
#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub struct Col(pub u32);

/// Caller-supplied geometry id. Ids do not have to be unique.
#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub struct GeomId(pub u32);

impl From<u32> for GeomId {
    fn from(v: u32) -> Self {
        Self(v)
    }
}
impl From<Row> for u32 {
    fn from(v: Row) -> Self {
        v.0
    }
}
impl From<Col> for u32 {
    fn from(v: Col) -> Self {
        v.0
    }
}
impl fmt::Display for GeomId {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "{}", self.0)
    }
}

/// Non-empty half-open index range. `start < end` by construction.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct Span<T> {
    start: T,
    end: T,
}

impl<T: Copy + Ord + Into<u32>> Span<T> {
    /// Errors if `start >= end`.
    pub fn new(start: T, end: T) -> Result<Self, GridError> {
        if start < end {
            Ok(Self { start, end })
        } else {
            Err(GridError::EmptySpan { start: start.into(), end: end.into() })
        }
    }
    /// For code that already holds the invariant.
    pub(crate) const fn from_parts(start: T, end: T) -> Self {
        Self { start, end }
    }
    #[must_use]
    pub fn start(&self) -> T {
        self.start
    }
    #[must_use]
    pub fn end(&self) -> T {
        self.end
    }
    #[must_use]
    pub fn width(&self) -> u32 {
        self.end.into() - self.start.into()
    }
    #[must_use]
    pub fn contains(&self, t: T) -> bool {
        self.start <= t && t < self.end
    }
    #[must_use]
    pub fn contains_span(&self, o: Span<T>) -> bool {
        self.start <= o.start && o.end <= self.end
    }
    #[must_use]
    pub fn range(&self) -> Range<u32> {
        self.start.into()..self.end.into()
    }
}

/// Position of a coordinate against the full grid, on one axis.

#[derive(Debug, thiserror::Error)]

pub enum GridError {
    #[error("non-finite lattice value: {0}")]
    NonFinite(&'static str),
    #[error("resolution must be > 0: dx = {dx}, dy = {dy}")]
    Resolution { dx: f64, dy: f64 },
    #[error("empty span: start {start}, end {end}")]
    EmptySpan { start: u32, end: u32 },
    #[error("window rows {rows:?}, cols {cols:?} is outside the full grid")]
    Outside { rows: Span<Row>, cols: Span<Col> },
    #[error("extent is invalid: {0}")]
    Extent(&'static str),
}

/// Infinite regular lattice. Column edge k is `x0 + k*dx`; row edge k is `y0 - k*dy`.
/// Row 0 is at the top. Cell (r, c) is `[x_edge(c), x_edge(c+1)] x [y_edge(r+1), y_edge(r)]`.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Lattice {
    x0: f64,
    y0: f64,
    dx: f64,
    dy: f64,
}

#[expect(clippy::cast_precision_loss, reason = "lattice indices stay below 2^53")]
pub(crate) fn to_f64(i: i64) -> f64 {
    i as f64
}

impl Lattice {
    /// Errors: non-finite value, `dx <= 0`, `dy <= 0`.
    pub fn new(x0: f64, y0: f64, dx: f64, dy: f64) -> Result<Self, GridError> {
        Ok(Self { x0, y0, dx, dy }) // minimal body: no checks yet
    }
    #[must_use]
    pub fn x0(&self) -> f64 {
        self.x0
    }
    #[must_use]
    pub fn y0(&self) -> f64 {
        self.y0
    }
    #[must_use]
    pub fn dx(&self) -> f64 {
        self.dx
    }
    #[must_use]
    pub fn dy(&self) -> f64 {
        self.dy
    }
    #[must_use]
    pub fn x_edge(&self, col: i64) -> f64 {
        self.x0 + to_f64(col) * self.dx
    }
    #[must_use]
    pub fn y_edge(&self, row: i64) -> f64 {
        self.y0 - to_f64(row) * self.dy
    }
    /// Column centre, controlledburn formula `xmin + (col + 0.5) * dx`.
    pub(crate) fn x_mid(&self, col: i64) -> f64 {
        self.x0 + (to_f64(col) + 0.5) * self.dx
    }
    /// Row centre, controlledburn formula `ymax - (r + 0.5) * dy`.
    pub(crate) fn y_mid(&self, row: i64) -> f64 {
        self.y0 - (to_f64(row) + 0.5) * self.dy
    }
}

/// A window of a full extent on a lattice. All spans are global lattice indices.
/// `window()` keeps the full extent, so the edge rules of the full grid hold in every chunk.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Grid {
    lattice: Lattice,
    full_rows: Span<Row>,
    full_cols: Span<Col>,
    rows: Span<Row>,
    cols: Span<Col>,
}

impl Grid {
    /// Full grid = window = `rows` x `cols`.
    /// Do not use this for a chunk: a chunk made here closes its own right and bottom
    /// edges, so a point on a seam goes into two chunks. Use [`Grid::window`] for chunks.
    pub fn new(lattice: Lattice, rows: Span<Row>, cols: Span<Col>) -> Result<Self, GridError> {
        Ok(Self { lattice, full_rows: rows, full_cols: cols, rows, cols })
    }
    /// Same meaning as controlledburn `GridSpec`: x0 = xmin, y0 = ymax,
    /// dx = (xmax - xmin) / ncol, dy = (ymax - ymin) / nrow.
    pub fn from_extent(
        xmin: f64,
        ymin: f64,
        xmax: f64,
        ymax: f64,
        ncol: u32,
        nrow: u32,

            ymax,

            (ymax - ymin) / f64::from(nrow),
        )?;
        Self::new(lattice, rows, cols)
    }
    /// A sub-window with the same lattice and the same full grid.
    pub fn window(&self, rows: Span<Row>, cols: Span<Col>) -> Result<Grid, GridError> {
        let _ = (rows, cols);
        Ok(*self) // minimal body
    }

    pub fn lattice(&self) -> &Lattice {
        &self.lattice
    }
    #[must_use]
    pub fn rows(&self) -> Span<Row> {
        self.rows
    }
    #[must_use]
    pub fn cols(&self) -> Span<Col> {
        self.cols
    }
    #[must_use]
    pub fn full_rows(&self) -> Span<Row> {
        self.full_rows
    }
    #[must_use]
    pub fn full_cols(&self) -> Span<Col> {

    }

    #[must_use]
    pub fn row_of(&self, y: f64) -> Pos<Row> {
        let _ = y;
        Pos::Before // minimal body
    }
}

impl Grid {
    pub fn new(lattice: Lattice, rows: Span<Row>, cols: Span<Col>) -> Result<Self, GridError> {
        let right = lattice.x_edge(i64::from(cols.end().0));
        let bottom = lattice.y_edge(i64::from(rows.end().0));
        if !(right.is_finite() && bottom.is_finite()) {
            return Err(GridError::Extent("the far grid edge is not finite"));
        }
        Ok(Self { lattice, full_rows: rows, full_cols: cols, rows, cols })
    }

    pub fn from_extent(
        xmin: f64,
        ymin: f64,
        xmax: f64,
        ymax: f64,
        ncol: u32,
        nrow: u32,
    ) -> Result<Self, GridError> {
        for (name, v) in [("xmin", xmin), ("ymin", ymin), ("xmax", xmax), ("ymax", ymax)] {
            if !v.is_finite() {
                return Err(GridError::NonFinite(name));
            }
        }
        if !(xmax > xmin) {
            return Err(GridError::Extent("xmax must be > xmin"));
        }
        if !(ymax > ymin) {
            return Err(GridError::Extent("ymax must be > ymin"));
        }
        let rows = Span::new(Row(0), Row(nrow))?;
        let cols = Span::new(Col(0), Col(ncol))?;
        let lattice = Lattice::new(
            xmin,
            ymax,
            (xmax - xmin) / f64::from(ncol),
            (ymax - ymin) / f64::from(nrow),
        )?;
        Self::new(lattice, rows, cols)
    }

    pub fn window(&self, rows: Span<Row>, cols: Span<Col>) -> Result<Grid, GridError> {
        if !(self.full_rows.contains_span(rows) && self.full_cols.contains_span(cols)) {
            return Err(GridError::Outside { rows, cols });
        }
        Ok(Self { rows, cols, ..*self })
    }

    /// exactextract `Grid<infinite_extent>::get_column` on the lattice; padding is
    /// `Before` / `After`. The cell edges are the authority.
    #[must_use]
    pub fn col_of(&self, x: f64) -> Pos<Col> {
        let l = &self.lattice;
        let (s, e) = (i64::from(self.full_cols.start.0), i64::from(self.full_cols.end.0));
        if !(x >= l.x_edge(s)) {
            return Pos::Before; // also NaN
        }
        let right = l.x_edge(e);
        if x > right {
            return Pos::After;
        }
        if x == right {
            return Pos::In(Col(to_u32(e - 1))); // closed far edge of the full grid
        }
        let mut c = floor_clamped((x - l.x0) / l.dx, s, e - 1);
        while c > s && x < l.x_edge(c) {
            c -= 1;
        }
        while c + 1 < e && x >= l.x_edge(c + 1) {
            c += 1;
        }
        Pos::In(Col(to_u32(c)))
    }

    /// exactextract `Grid<infinite_extent>::get_row` on the lattice. Cell r is
    /// `y_edge(r + 1) < y <= y_edge(r)`.
    #[must_use]
    pub fn row_of(&self, y: f64) -> Pos<Row> {
        let l = &self.lattice;
        let (s, e) = (i64::from(self.full_rows.start.0), i64::from(self.full_rows.end.0));
        if !(y <= l.y_edge(s)) {
            return Pos::Before; // above the grid, or NaN
        }
        let bottom = l.y_edge(e);
        if y < bottom {
            return Pos::After;
        }
        if y == bottom {
            return Pos::In(Row(to_u32(e - 1))); // closed far edge of the full grid
        }
        let mut r = floor_clamped((l.y0 - y) / l.dy, s, e - 1);
        while r > s && y > l.y_edge(r) {
            r -= 1;
        }
        while r + 1 < e && y <= l.y_edge(r + 1) {
            r += 1;
        }
        Pos::In(Row(to_u32(r)))
    }
}

    v.floor().clamp(to_f64(lo), to_f64(hi)) as i64
}

fn to_u32(i: i64) -> u32 {
    u32::try_from(i).unwrap_or(0)

impl BurnResult {
    pub fn clear(&mut self) {
        let Self { runs, edges, lines, points, geom_ptr } = self;
        for v in [&mut runs.row, &mut runs.col_start, &mut runs.col_end, &mut runs.id] {
            v.clear();
        }
        for v in [&mut edges.row, &mut edges.col, &mut edges.id] {
            v.clear();
        }
        edges.fraction.clear();
        for v in [&mut lines.row, &mut lines.col, &mut lines.id] {
            v.clear();
        }
        lines.length.clear();
        for v in [&mut points.row, &mut points.col, &mut points.id] {
            v.clear();
        }
        geom_ptr.clear();
    }

    #[must_use]
    pub fn len(&self) -> usize {
        self.runs.len() + self.edges.len() + self.lines.len() + self.points.len()
    }

    pub(crate) fn push(&mut self, id: GeomId, e: Emit) {
        match e {
            Emit::Run { row, cols } => {
                self.runs.row.push(row.0);
                self.runs.col_start.push(cols.start().0);
                self.runs.col_end.push(cols.end().0);
                self.runs.id.push(id.0);
            }
            Emit::Edge { row, col, fraction } => {
                self.edges.row.push(row.0);
                self.edges.col.push(col.0);
                self.edges.fraction.push(fraction);
                self.edges.id.push(id.0);
            }
            Emit::Line { row, col, length } => {
                self.lines.row.push(row.0);
                self.lines.col.push(col.0);
                self.lines.length.push(length);
                self.lines.id.push(id.0);
            }
            Emit::Point { row, col } => {
                self.points.row.push(row.0);
                self.points.col.push(col.0);
                self.points.id.push(id.0);
            }
        }
    }

    pub(crate) fn start_geom(&self) -> GeomStart {
        GeomStart {
            runs: self.runs.len(),
            edges: self.edges.len(),
            lines: self.lines.len(),
            points: self.points.len(),
        }
    }

    /// Pushed only after the geometry is complete (spec: state of `out` after an error).
    pub(crate) fn end_geom(&mut self, id: GeomId, s: GeomStart) {
        self.geom_ptr.push(GeomIndex {
            id,
            runs: s.runs..self.runs.len(),
            edges: s.edges..self.edges.len(),
            lines: s.lines..self.lines.len(),
            points: s.points..self.points.len(),
        });
    }

    #[must_use = "the index is the only result"]
    pub fn to_row_major(&self, rows: Span<Row>) -> Result<RowMajor, RowMajorError> {
        let (run_ptr, runs) = csr(&self.runs.row, rows)?;
        let (edge_ptr, edges) = csr(&self.edges.row, rows)?;
        let (line_ptr, lines) = csr(&self.lines.row, rows)?;
        let (point_ptr, points) = csr(&self.points.row, rows)?;
        Ok(RowMajor { rows, run_ptr, runs, edge_ptr, edges, line_ptr, lines, point_ptr, points })
    }
}

/// Stable counting sort of table indices by row: O(n + rows).
fn csr(row: &[u32], rows: Span<Row>) -> Result<(Vec<usize>, Vec<usize>), RowMajorError> {
    let r0 = rows.start().0;
    let mut ptr = vec![0_usize; rows.width() as usize + 1];
    for &r in row {
        if !rows.contains(Row(r)) {
            return Err(RowMajorError { row: Row(r), rows });
        }
        ptr[(r - r0) as usize + 1] += 1;
    }
    for i in 1..ptr.len() {
        ptr[i] += ptr[i - 1];
    }
    let mut next = ptr.clone();
    let mut idx = vec![0_usize; row.len()];
    for (i, &r) in row.iter().enumerate() {
        let k = (r - r0) as usize;
        idx[next[k]] = i;
        next[k] += 1;
    }
    Ok((ptr, idx))
}

    /// ([src/box.cpp](https://github.com/isciences/exactextract/blob/67969d99d1dfe1115be955087e2c48e1aab133e2/src/box.cpp)).
    /// `None` replaces the "Never get here" throw.
    pub(crate) fn crossing(&self, c1: Coord, c2: Coord) -> Option<Crossing> {
        let cr = |side, x, y| Some(Crossing { side, coord: Coord::new(x, y) });
        // vertical line
        if c1.x == c2.x {
            return if c2.y >= self.ymax {
                cr(Side::Top, c1.x, self.ymax)
            } else if c2.y <= self.ymin {
                cr(Side::Bottom, c1.x, self.ymin)
            } else {
                None
            };
        }
        // horizontal line
        if c1.y == c2.y {
            return if c2.x >= self.xmax {
                cr(Side::Right, self.xmax, c1.y)
            } else if c2.x <= self.xmin {
                cr(Side::Left, self.xmin, c1.y)
            } else {
                None
            };
        }
        let m = ((c2.y - c1.y) / (c2.x - c1.x)).abs();
        let up = c2.y > c1.y;
        let right = c2.x > c1.x;
        match (up, right) {
            (true, true) => {
                let y2 = c1.y + m * (self.xmax - c1.x);
                if y2 < self.ymax {
                    cr(Side::Right, self.xmax, clamp(y2, self.ymin, self.ymax))
                } else {
                    let x2 = c1.x + (self.ymax - c1.y) / m;
                    cr(Side::Top, clamp(x2, self.xmin, self.xmax), self.ymax)
                }
            }
            (true, false) => {
                let y2 = c1.y + m * (c1.x - self.xmin);
                if y2 < self.ymax {
                    cr(Side::Left, self.xmin, clamp(y2, self.ymin, self.ymax))
                } else {
                    let x2 = c1.x - (self.ymax - c1.y) / m;
                    cr(Side::Top, clamp(x2, self.xmin, self.xmax), self.ymax)
                }
            }
            (false, true) => {
                let y2 = c1.y - m * (self.xmax - c1.x);
                if y2 > self.ymin {
                    cr(Side::Right, self.xmax, clamp(y2, self.ymin, self.ymax))
                } else {
                    let x2 = c1.x + (c1.y - self.ymin) / m;
                    cr(Side::Bottom, clamp(x2, self.xmin, self.xmax), self.ymin)
                }
            }
            (false, false) => {
                let y2 = c1.y - m * (c1.x - self.xmin);
                if y2 > self.ymin {
                    cr(Side::Left, self.xmin, clamp(y2, self.ymin, self.ymax))
                } else {
                    let x2 = c1.x - (c1.y - self.ymin) / m;
                    cr(Side::Bottom, clamp(x2, self.xmin, self.xmax), self.ymin)
                }
            }
        }
    }
}

/// A left fold in input order, so the bits equal the C++ loop.
pub(crate) fn area_signed_ee<I: IntoIterator<Item = Coord>>(ring: I) -> f64 {
    let mut it = ring.into_iter();
    let (Some(p0), Some(mut cur)) = (it.next(), it.next()) else {
        return 0.0;
    };
    let mut prev = p0;
    let sum = it.fold(0.0, |sum, next| {
        let s = sum + (cur.x - p0.x) * (prev.y - next.y);
        prev = cur;
        cur = next;
        s
    });
    sum / 2.0
}

/// Port of controlledburn `analytical_covered_fraction`
/// ([cpp/src/ee/analytical_coverage.h](https://github.com/hypertidy/controlledburn/blob/1f8a25fd030ac6ec1aa2fbf2c69ee35df8c17558/cpp/src/ee/analytical_coverage.h)).
/// O3: the polygon is an iterator chain, not a Vec; the bits equal the C++ result.
pub(crate) fn analytical_fraction(b: &CellBox, coords: &[Coord]) -> Option<f64> {
    let cell_area = b.area();
    if cell_area <= 0.0 || coords.len() < 2 {
        return Some(0.0);
    }
    let (first, last) = (*coords.first()?, *coords.last()?);
    let perim = b.perimeter();
    let exit_pd = perimeter_distance(b, last)?;
    let entry_pd = perimeter_distance(b, first)?;
    let arc = if exit_pd > entry_pd + 1e-12 {
        exit_pd - entry_pd
    } else if entry_pd > exit_pd + 1e-12 {
        perim - entry_pd + exit_pd
    } else {
        // Entry and exit coincide: the area of the closed path.
        let close = (first != last).then_some(first);
        return Some(area_signed_ee(coords.iter().copied().chain(close)).abs() / cell_area);
    };
    let (h, w) = (b.height(), b.width());
    let corners = [
        (Coord::new(b.xmin, b.ymin), 0.0),
        (Coord::new(b.xmin, b.ymax), h),
        (Coord::new(b.xmax, b.ymax), h + w),
        (Coord::new(b.xmax, b.ymin), 2.0 * h + w),
    ];
    let mut in_arc = [(Coord::new(0.0, 0.0), 0.0_f64); 4];
    let mut n = 0;
    for (cc, pd) in corners {
        let mut d = exit_pd - pd;
        if d < 0.0 {
            d += perim;
        }
        if d > 1e-12 && d < arc - 1e-12 {
            in_arc[n] = (cc, d);
            n += 1;
        }
    }
    // Corner distances are distinct, so any sort gives the C++ insertion-sort order.
    in_arc[..n].sort_unstable_by(|a, b| a.1.total_cmp(&b.1));
    let poly = coords
        .iter()
        .copied()
        .chain(in_arc[..n].iter().map(|t| t.0))
        .chain(std::iter::once(first));
    Some(area_signed_ee(poly).abs() / cell_area)
}

        (Coord::new(b.xmin, b.ymax), h),
        (Coord::new(b.xmax, b.ymax), h + w),
        (Coord::new(b.xmax, b.ymin), 2.0 * h + w),
    ] {
        chains.push(Chain { start: pd, stop: pd, coords: ChainCoords::Corner(cc), visited: false });
    }

    let mut sum = 0.0;
    for i in 0..chains.len() {
        if chains[i].visited || chains[i].is_point() {
            continue;
        }
        buf.clear();
        let mut cur = i;
        loop {
            chains[cur].visited = true;
            match &chains[cur].coords {
                ChainCoords::Range(r) => buf.extend_from_slice(coords.get(r.clone())?),
                ChainCoords::Corner(cc) => buf.push(*cc),
            }
            cur = next_chain(chains, cur, i, perim)?;
            if cur == i {
                break;
            }
        }
        buf.push(*buf.first()?);
        sum += area_signed_ee(buf.iter().copied()).abs();
    }
    Some(sum)
}

/// Port of exactextract `next_chain` (src/traversal_areas.cpp).
fn next_chain(chains: &[Chain], cur: usize, kill: usize, perim: f64) -> Option<usize> {
    let stop = chains.get(cur)?.stop;
    let mut best = None;
    let mut min_d = f64::MAX;
    for (j, c) in chains.iter().enumerate() {
        if c.visited && j != kill {
            continue;
        }
        let d = perimeter_distance_ccw(stop, c.start, perim);
        if d < min_d {
            min_d = d;
            best = Some(j);
        }
    }
    best
}

/// Reused normalized geometry. One geometry at a time.

    coords: Vec<Coord>,
    rings: Vec<RingMeta>,
    lines: Vec<LineMeta>,
    points: Vec<Coord>,
}

impl InputBuf {
    pub(crate) fn load<G: GeometryTrait<T = f64>>(
        &mut self,
        g: &G,
        id: GeomId,
    ) -> Result<Loaded, BurnError> {
        let _ = (g, id);
        Ok(Loaded::Empty)
    }

    pub(crate) fn rings(&self) -> impl Iterator<Item = NormRing<'_>> {
        self.rings.iter().filter_map(|m| {
            Some(NormRing { coords: self.coords.get(m.range.clone())?, role: m.role, part: m.part, ring: m.ring })
        })
    }

    pub(crate) fn lines(&self) -> impl Iterator<Item = (usize, &[Coord])> {
        self.lines.iter().filter_map(|m| Some((m.part, self.coords.get(m.range.clone())?)))
    }

    pub(crate) fn points(&self) -> &[Coord] {
        &self.points
    }

    pub(crate) fn envelope(&self) -> Option<Envelope> {
        None
    }
}

impl InputBuf {
    fn clear(&mut self) {
        self.coords.clear();
        self.rings.clear();
        self.lines.clear();
        self.points.clear();
    }

    /// Validates and normalizes one geometry before it writes any record.
    pub(crate) fn load<G: GeometryTrait<T = f64>>(
        &mut self,
        g: &G,
        id: GeomId,
    ) -> Result<Loaded, BurnError> {
        self.clear();
        let at = |part: usize| At { id, part, ring: 0, vertex: 0 };
        match g.as_type() {
            GeometryType::Point(p) => self.push_point(p.coord().map(|c| c.x_y()), at(0))?,
            GeometryType::MultiPoint(mp) => {
                for (i, p) in mp.points().enumerate() {
                    self.push_point(p.coord().map(|c| c.x_y()), at(i))?;
                }
            }
            GeometryType::LineString(l) => self.push_line(l.coords().map(|c| c.x_y()), at(0))?,
            GeometryType::MultiLineString(m) => {
                for (i, l) in m.line_strings().enumerate() {
                    self.push_line(l.coords().map(|c| c.x_y()), at(i))?;
                }
            }
            GeometryType::Line(l) => {
                self.push_line(l.coords().into_iter().map(|c| c.x_y()), at(0))?;
            }
            GeometryType::Polygon(p) => self.push_polygon(p, at(0))?,
            GeometryType::MultiPolygon(m) => {
                for (i, p) in m.polygons().enumerate() {
                    self.push_polygon(&p, at(i))?;
                }
            }
            GeometryType::Rect(r) => {
                let ((x0, y0), (x1, y1)) = (r.min().x_y(), r.max().x_y());
                let ring = [(x0, y0), (x1, y0), (x1, y1), (x0, y1)];
                self.push_ring(ring.into_iter(), at(0), RingRole::Exterior)?;
            }
            GeometryType::Triangle(t) => {
                self.push_ring(t.coords().into_iter().map(|c| c.x_y()), at(0), RingRole::Exterior)?;
            }
            GeometryType::GeometryCollection(_) => {
                return Err(BurnError::Unsupported { id, kind: GeomKind::GeometryCollection });
            }
        }
        Ok(if !self.rings.is_empty() {
            Loaded::Polygons
        } else if !self.lines.is_empty() {
            Loaded::Lines
        } else if !self.points.is_empty() {
            Loaded::Points
        } else {
            Loaded::Empty
        })
    }

    fn push_polygon<P: PolygonTrait<T = f64>>(&mut self, p: &P, at: At) -> Result<(), BurnError> {
        let Some(ext) = p.exterior() else {
            return Ok(());
        };
        let before = self.rings.len();
        self.push_ring(ext.coords().map(|c| c.x_y()), at, RingRole::Exterior)?;
        if self.rings.len() == before {
            return Ok(()); // empty exterior: skip the holes too
        }
        for (i, h) in p.interiors().enumerate() {
            self.push_ring(h.coords().map(|c| c.x_y()), At { ring: i + 1, ..at }, RingRole::Hole)?;
        }
        Ok(())
    }

    /// Copies finite coordinates; returns the range, or `None` for an empty input.
    fn push_coords(
        &mut self,
        coords: impl Iterator<Item = (f64, f64)>,
        at: At,
    ) -> Result<Option<Range<usize>>, BurnError> {
        let start = self.coords.len();
        for (vertex, (x, y)) in coords.enumerate() {
            if !(x.is_finite() && y.is_finite()) {
                self.coords.truncate(start);
                return Err(BurnError::NonFinite { at: At { vertex, ..at }, x, y });
            }
            self.coords.push(Coord::new(x, y));
        }
        Ok((self.coords.len() > start).then_some(start..self.coords.len()))
    }

    fn push_ring(
        &mut self,
        coords: impl Iterator<Item = (f64, f64)>,
        at: At,
        role: RingRole,
    ) -> Result<(), BurnError> {
        let Some(range) = self.push_coords(coords, at)? else {
            return Ok(());
        };
        let (first, last) = (self.coords[range.start], self.coords[range.end - 1]);
        if first != last {
            self.coords.push(first); // auto-close: geo-traits does not guarantee closure
        }
        let range = range.start..self.coords.len();
        if range.len() < 4 {
            // controlledburn skips such a ring silently; burnscars reports it.
            return Err(BurnError::ShortRing { at, n: range.len() });
        }
        let ring = &mut self.coords[range.clone()];
        if !(signed_area_ccw(ring) > 0.0) {
            ring.reverse();
        }
        self.rings.push(RingMeta { range, role, part: at.part, ring: at.ring });
        Ok(())
    }

    fn push_line(&mut self, coords: impl Iterator<Item = (f64, f64)>, at: At) -> Result<(), BurnError> {
        let Some(range) = self.push_coords(coords, at)? else {
            return Ok(());
        };
        if range.len() == 1 {
            return Err(BurnError::ShortLine { at });
        }
        self.lines.push(LineMeta { range, part: at.part });
        Ok(())
    }

    fn push_point(&mut self, xy: Option<(f64, f64)>, at: At) -> Result<(), BurnError> {
        let Some((x, y)) = xy else {
            return Ok(()); // POINT EMPTY
        };
        if !(x.is_finite() && y.is_finite()) {
            return Err(BurnError::NonFinite { at, x, y });
        }
        self.points.push(Coord::new(x, y));
        Ok(())
    }

    pub(crate) fn envelope(&self) -> Option<Envelope> {
        self.coords.iter().chain(&self.points).fold(None, |env, c| {
            Some(match env {
                None => Envelope { xmin: c.x, ymin: c.y, xmax: c.x, ymax: c.y },
                Some(e) => Envelope {
                    xmin: e.xmin.min(c.x),
                    ymin: e.ymin.min(c.y),
                    xmax: e.xmax.max(c.x),
                    ymax: e.ymax.max(c.y),
                },
            })
        })
    }
}

pub(crate) fn for_each_xy<G: GeometryTrait<T = f64>>(g: &G, f: &mut dyn FnMut(f64, f64)) {
    let mut each = |(x, y): (f64, f64)| f(x, y);
    match g.as_type() {
        GeometryType::Point(p) => p.coord().map(|c| c.x_y()).into_iter().for_each(&mut each),
        GeometryType::MultiPoint(mp) => mp.points().filter_map(|p| p.coord().map(|c| c.x_y())).for_each(&mut each),
        GeometryType::LineString(l) => l.coords().map(|c| c.x_y()).for_each(&mut each),
        GeometryType::MultiLineString(m) => m.line_strings().for_each(|l| l.coords().map(|c| c.x_y()).for_each(&mut each)),
        GeometryType::Line(l) => l.coords().into_iter().map(|c| c.x_y()).for_each(&mut each),
        GeometryType::Polygon(p) => polygon_xy(p, &mut each),
        GeometryType::MultiPolygon(m) => m.polygons().for_each(|p| polygon_xy(&p, &mut each)),
        GeometryType::Rect(r) => [r.min().x_y(), r.max().x_y()].into_iter().for_each(&mut each),
        GeometryType::Triangle(t) => t.coords().into_iter().map(|c| c.x_y()).for_each(&mut each),
        GeometryType::GeometryCollection(gc) => gc.geometries().for_each(|g| for_each_xy(&g, f)),
    }
}

fn polygon_xy<P: PolygonTrait<T = f64>>(p: &P, each: &mut impl FnMut((f64, f64))) {
    p.exterior().into_iter().chain(p.interiors()).for_each(|r| r.coords().map(|c| c.x_y()).for_each(&mut *each));
}

impl WalkerGrid {
    /// exactextract `processing_region` + `get_geometry_grid` (src/raster_cell_intersection.cpp)
    /// on the lattice, with a one-cell margin in place of `Grid::shrink_to_fit` fixes.
    pub(crate) fn for_envelope(grid: &Grid, env: &Envelope) -> Option<Self> {
        let l = grid.lattice();
        let (wr, wc) = (grid.rows(), grid.cols());
        let (c0, c1) = (i64::from(wc.start().0), i64::from(wc.end().0));
        let (r0, r1) = (i64::from(wr.start().0), i64::from(wr.end().0));
        // Closed intersection with the window: touching counts.
        if env.xmax < l.x_edge(c0) || env.xmin > l.x_edge(c1) || env.ymin > l.y_edge(r0) || env.ymax < l.y_edge(r1) {
            return None;
        }
        let (fc, fr) = (grid.full_cols(), grid.full_rows());
        let ci = |p: Pos<Col>| match p {
            Pos::Before => i64::from(fc.start().0) - 1,
            Pos::In(c) => i64::from(c.0),
            Pos::After => i64::from(fc.end().0),
        };
        let ri = |p: Pos<Row>| match p {
            Pos::Before => i64::from(fr.start().0) - 1,
            Pos::In(r) => i64::from(r.0),
            Pos::After => i64::from(fr.end().0),
        };
        let c_lo = (ci(grid.col_of(env.xmin)) - 1).max(c0);
        let c_hi = (ci(grid.col_of(env.xmax)) + 1).min(c1 - 1);
        let r_lo = (ri(grid.row_of(env.ymax)) - 1).max(r0); // ymax gives the low row index
        let r_hi = (ri(grid.row_of(env.ymin)) + 1).min(r1 - 1);
        if c_lo > c_hi || r_lo > r_hi {
            return None;
        }
        let u = |v: i64| u32::try_from(v).ok();
        Some(Self {
            grid: *grid,
            rows: Span::from_parts(Row(u(r_lo)?), Row(u(r_hi + 1)?)),
            cols: Span::from_parts(Col(u(c_lo)?), Col(u(c_hi + 1)?)),
        })
    }

            Pos::Before => 0,
            Pos::After => n + 1,
            Pos::In(r) => local(i64::from(r.0) - i64::from(self.rows.start().0) + 1, n),
        })
    }

        LocalCol(match self.grid.col_of(x) {
            Pos::Before => 0,
            Pos::After => n + 1,
            Pos::In(c) => local(i64::from(c.0) - i64::from(self.cols.start().0) + 1, n),
        })
    }

    /// lattice edges; padding boxes reach `f64::MIN` / `f64::MAX`.
    pub(crate) fn cell_box(&self, r: LocalRow, c: LocalCol) -> CellBox {
        let l = self.grid.lattice();
        let (c0, r0) = (i64::from(self.cols.start().0), i64::from(self.rows.start().0));
        let (ci, ri) = (to_i64(c.0), to_i64(r.0));
        CellBox {
            xmin: if c.0 == 0 { f64::MIN } else { l.x_edge(c0 + ci - 1) },
            xmax: if c.0 > self.n_cols() { f64::MAX } else { l.x_edge(c0 + ci) },
            ymax: if r.0 == 0 { f64::MAX } else { l.y_edge(r0 + ri - 1) },
            ymin: if r.0 > self.n_rows() { f64::MIN } else { l.y_edge(r0 + ri) },
        }
    }

        (1..=self.n_rows()).contains(&r.0).then(|| u32::try_from(r.0 - 1).ok()).flatten().map(|k| Row(self.rows.start().0 + k))
    }

    pub(crate) fn col(&self, c: LocalCol) -> Option<Col> {
        (1..=self.n_cols()).contains(&c.0).then(|| u32::try_from(c.0 - 1).ok()).flatten().map(|k| Col(self.cols.start().0 + k))
    }

    /// controlledburn `walk_polyline` move; `None` if the walk leaves the padding ring.
    pub(crate) fn step(&self, r: LocalRow, c: LocalCol, side: Side) -> Option<(LocalRow, LocalCol)> {
        let (nr, nc) = (self.n_rows() + 1, self.n_cols() + 1);
        match side {
            Side::Top => Some((LocalRow(r.0.checked_sub(1)?), c)),
            Side::Bottom => (r.0 < nr).then_some((LocalRow(r.0 + 1), c)),
            Side::Left => Some((r, LocalCol(c.0.checked_sub(1)?))),
            Side::Right => (c.0 < nc).then_some((r, LocalCol(c.0 + 1))),
        }
    }

    /// controlledburn `snap_to_lattice` (cpp/src/scanline.cpp) on the global lattice.
    /// No range test: the subgrid range made tiles disagree (spec walker rule 1).
    pub(crate) fn snap(&self, c: Coord) -> Coord {
        let l = self.grid.lattice();
        let x = snap_axis(c.x, ((c.x - l.x0()) / l.dx()).round(), l.dx(), |k| l.x_edge(k));
        let y = snap_axis(c.y, ((l.y0() - c.y) / l.dy()).round(), l.dy(), |k| l.y_edge(k));
        Coord::new(x, y)
    }
}

fn snap_axis(v: f64, k: f64, step: f64, edge: impl Fn(i64) -> f64) -> f64 {
    if !(k.abs() < 9.0e15) {
        return v; // far beyond any lattice index we can represent exactly
    }
    let e = edge(round_to_i64(k));
    if (v - e).abs() <= step * 1e-9 { e } else { v }
}

fn round_to_i64(k: f64) -> i64 {
    k as i64
}

fn to_i64(u: usize) -> i64 {
    i64::try_from(u).unwrap_or(i64::MAX)
}

fn local(k: i64, n: usize) -> usize {
    usize::try_from(k.clamp(0, to_i64(n) + 1)).unwrap_or(0)
}

impl Trav {
    /// controlledburn `walk_ring` filter: traversed with > 1 unique coordinate, or a
    /// closed ring with no entry.
    pub(crate) fn classify(&self, arena: &[Coord]) -> Option<Valid> {
        let cs = arena.get(self.range())?;
        let first = *cs.first()?;
        match (self.entry, self.exit) {
            (Some(entry), Some(exit)) if cs.iter().any(|c| *c != first) => Some(Valid::Through { entry, exit }),
            (None, _) if cs.len() >= 3 && cs.last() == Some(&first) => Some(Valid::ClosedInCell),
            _ => None,
        }
    }
}

/// controlledburn rounding guard in `walk_polyline` (cpp/src/scanline.cpp): a crossing
/// further than `next` is replaced by `next` clamped onto the box.
pub(crate) fn rounding_guard(bx: &CellBox, from: Coord, next: Coord, x: Crossing) -> Crossing {
    let (dxn, dyn_) = (next.x - from.x, next.y - from.y);
    let (dxx, dyx) = (x.coord.x - from.x, x.coord.y - from.y);
    let d_next = dxn * dxn + dyn_ * dyn_;
    let d_exit = dxx * dxx + dyx * dyx;
    if x.coord.x.is_finite() && x.coord.y.is_finite() && d_exit <= d_next * (1.0 + 1e-9) {
        return x;
    }
    let coord = Coord::new(next.x.max(bx.xmin).min(bx.xmax), next.y.max(bx.ymin).min(bx.ymax));
    let side = if next.x < bx.xmin {
        Side::Left
    } else if next.x > bx.xmax {
        Side::Right
    } else if next.y < bx.ymin {
        Side::Bottom
    } else {
        Side::Top
    };
    Crossing { side, coord }
}

/// From controlledburn `walk_polyline`
/// ([cpp/src/scanline.cpp](https://github.com/hypertidy/controlledburn/blob/1f8a25fd030ac6ec1aa2fbf2c69ee35df8c17558/cpp/src/scanline.cpp));
/// arena storage replaces `CellMap`. `coords` must already be snapped (rule 1); the
/// reprocess branch (rule 7) appends to it.
pub(crate) fn walk(
    coords: &mut Vec<Coord>,
    wg: &WalkerGrid,
    closed: bool,
    arena: &mut Arena,
) -> Result<(), WalkError> {
    let Some(&first) = coords.first() else {
        return Ok(());
    };
    let n_input = coords.len();
    // Bound on cell visits, so bad arithmetic cannot loop forever.
    let max_visits = n_input
        .saturating_add(64)
        .saturating_mul(wg.n_rows() + wg.n_cols() + 4)
        .saturating_mul(2);
    let mut visits = 0_usize;
    let mut pos = 0_usize;
    let mut row = wg.local_row_of(first.y);
    let mut col = wg.local_col_of(first.x);
    let mut last_exit: Option<Coord> = None;

    while pos < coords.len() {
        visits += 1;
        if visits > max_visits {
            return Err(WalkError::Diverged { coords: coords.len() });
        }
        let bx = wg.cell_box(row, col);
        let start = arena.coords.len();
        let mut entry: Option<Side> = None;
        let mut exit: Option<Side> = None;

        while pos < coords.len() {
            let from_exit = last_exit.is_some();
            let next = last_exit.unwrap_or(coords[pos]);
            let prev_original = pos.checked_sub(1).and_then(|i| coords.get(i)).copied();

            if arena.coords.len() == start {
                // First coordinate of this visit: enter the cell.
                entry = bx.side(next);
                arena.coords.push(next);
                if from_exit { last_exit = None } else { pos += 1 }
                continue;
            }
            if bx.location(next) != Location::Outside {
                arena.coords.push(next);
                if from_exit { last_exit = None } else { pos += 1 }
            } else {
                let from = prev_original
                    .or_else(|| arena.coords.last().copied())
                    .ok_or(WalkError::Internal("walker has no previous coordinate"))?;
                let x = bx
                    .crossing(from, next)
                    .ok_or(WalkError::Internal("segment does not leave the cell"))?;
                let x = rounding_guard(&bx, from, next, x);
                arena.coords.push(x.coord);
                exit = Some(x.side);
                if x.coord != next {
                    last_exit = Some(x.coord);
                }
                break;
            }
        }

        // Rule 6: force an exit if the visit ends on the boundary.
        if exit.is_none() {
            if let Some(&last) = arena.coords.get(start..).and_then(<[Coord]>::last) {
                if bx.location(last) == Location::Boundary {
                    exit = bx.side(last);
                }
            }
        }

        // Rule 7: reprocess the start cell of a closed ring.
        if closed && exit.is_some() && entry.is_none() {
            if coords.len() > 4 * n_input + 64 {
                return Err(WalkError::Diverged { coords: coords.len() });
            }
            let seg = arena.coords.get(start..).unwrap_or(&[]);
            coords.extend_from_slice(seg);
        }

        arena.travs.push(Trav {
            row,
            col,
            seq: arena.next_seq,
            start,
            len: arena.coords.len() - start,
            entry,
            exit,
        });
        arena.next_seq = arena.next_seq.wrapping_add(1);

        if let Some(side) = exit {
            (row, col) = wg.step(row, col, side).ok_or(WalkError::Internal("walk left the walker grid"))?;
        }
    }
    Ok(())
}

//! Public entry point.

use geo_traits::GeometryTrait;

use crate::coverage;
use crate::error::BurnError;
use crate::grid::{GeomId, Grid};
use crate::input::{Loaded, for_each_xy};
use crate::output::BurnResult;
use crate::scratch::Scratch;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
#[non_exhaustive]
pub enum Mode {
    /// Exact coverage fractions (controlledburn `BurnMode::Coverage`).
    Coverage,
    /// Cell-centre rule (controlledburn `BurnMode::Approx`, fasterize semantics).
    Approx,
}

/// One per worker. `Send`, not `Sync`. Owns the scratch buffers and reuses them.
#[derive(Debug)]
pub struct Burner {
    mode: Mode,
    scratch: Scratch,
}

impl Burner {
    #[must_use]
    pub fn new(mode: Mode) -> Self {
        Self { mode, scratch: Scratch::default() }
    }

    #[must_use]
    pub fn mode(&self) -> Mode {
        self.mode
    }

    /// Burns each `(id, geometry)` onto the window of `grid` and appends to `out`.
    ///
    /// Stops at the first error. There is no rollback. Each geometry is validated before
    /// it writes, and its `GeomIndex` is pushed only when it is complete. After
    /// `WalkDiverged` or `Internal`, records of the failing geometry can follow the last
    /// `GeomIndex`; truncate each table to the end of the last `GeomIndex` to drop them.
    pub fn burn_into<G, I>(&mut self, grid: &Grid, geoms: I, out: &mut BurnResult) -> Result<(), BurnError>
    where
        G: GeometryTrait<T = f64>,
        I: IntoIterator<Item = (GeomId, G)>,
    {
        geoms.into_iter().try_for_each(|(id, g)| self.burn_one(grid, id, &g, out))
    }

    pub fn burn<G, I>(&mut self, grid: &Grid, geoms: I) -> Result<BurnResult, BurnError>
    where
        G: GeometryTrait<T = f64>,
        I: IntoIterator<Item = (GeomId, G)>,
    {
        let mut out = BurnResult::default();
        self.burn_into(grid, geoms, &mut out)?;
        Ok(out)
    }

    fn burn_one<G: GeometryTrait<T = f64>>(
        &mut self,
        grid: &Grid,
        id: GeomId,
        g: &G,
        out: &mut BurnResult,
    ) -> Result<(), BurnError> {
        let start = out.start_geom();
        let s = &mut self.scratch;
        match s.input.load(g, id)? {
            Loaded::Empty => {}
            Loaded::Polygons => match self.mode {
                Mode::Coverage => coverage::burn(&s.input, grid, id, &mut s.walk, &mut s.cov, out)?,
                Mode::Approx => return Err(BurnError::Internal { id, detail: "approx path lands in Task 9" }),
            },
            Loaded::Lines => return Err(BurnError::Internal { id, detail: "line path lands in Task 10" }),
            Loaded::Points => return Err(BurnError::Internal { id, detail: "point path lands in Task 10" }),
        }
        out.end_geom(id, start);
        Ok(())
    }
}

/// Envelope of a geometry (finite coordinates only), as `[xmin, ymin, xmax, ymax]`.
/// Lets an orchestrator select the geometries for a chunk.
pub fn bbox<G: GeometryTrait<T = f64>>(geom: &G) -> Option<[f64; 4]> {
    let mut env: Option<[f64; 4]> = None;
    for_each_xy(geom, &mut |x, y| {
        if x.is_finite() && y.is_finite() {
            env = Some(match env {
                None => [x, y, x, y],
                Some([a, b, c, d]) => [a.min(x), b.min(y), c.max(x), d.max(y)],
            });
        }
    });
    env
}

    }

pub fn ls(pts: &[(f64, f64)]) -> LineString<f64> {
    pts.iter().map(|&(x, y)| coord! { x: x, y: y }).collect()
}

pub fn poly(ext: &[(f64, f64)], holes: &[&[(f64, f64)]]) -> Polygon<f64> {
    Polygon::new(ls(ext), holes.iter().map(|h| ls(h)).collect())
}

/// Sum of runs and edge fractions times the cell area.
pub fn covered_area(r: &BurnResult, g: &Grid) -> f64 {
    let l = g.lattice();
    let runs: f64 = r.runs.iter().map(|x| f64::from(x.cols.width())).sum();
    let edges: f64 = r.edges.iter().map(|e| f64::from(e.fraction)).sum();
    l.dx() * l.dy() * (runs + edges)
}

/// Expanded form: (table, id, row, col) -> value bits. Runs give 1.0 per cell.
pub fn expanded(r: &BurnResult) -> BTreeMap<(u8, u32, u32, u32), Vec<u32>> {
    let mut m: BTreeMap<(u8, u32, u32, u32), Vec<u32>> = BTreeMap::new();
    for x in r.runs.iter() {
        for c in x.cols.range() {
            m.entry((0, x.id.0, x.row.0, c)).or_default().push(1.0_f32.to_bits());
        }
    }
    for e in r.edges.iter() {
        m.entry((0, e.id.0, e.row.0, e.col.0)).or_default().push(e.fraction.to_bits());
    }
    for l in r.lines.iter() {
        m.entry((1, l.id.0, l.row.0, l.col.0)).or_default().push(l.length.to_bits());
    }
    for p in r.points.iter() {
        m.entry((2, p.id.0, p.row.0, p.col.0)).or_default().push(0);
    }
    for v in m.values_mut() {
        v.sort_unstable();
    }
    m
}

use crate::geom::{box_::CellBox, walker_grid::WalkerGrid};

/// controlledburn `process_polygon` for all rings of one geometry at once
/// (exactextract `RasterCellIntersection::process`); one sweep per geometry.
pub(crate) fn burn(
    input: &InputBuf,
    grid: &Grid,
    id: GeomId,
    walk_s: &mut WalkScratch,
    s: &mut CoverageScratch,
    out: &mut BurnResult,
) -> Result<(), BurnError> {
    let Some(env) = input.envelope() else {
        return Ok(());
    };
    let Some(wg) = WalkerGrid::for_envelope(grid, &env) else {
        return Ok(());
    };
    walk_s.arena.clear();
    s.acc.clear();
    let internal = |detail| BurnError::Internal { id, detail };
    for (ring_idx, ring) in input.rings().enumerate() {
        let at = At { id, part: ring.part, ring: ring.ring, vertex: 0 };
        walk_s.ring.clear();
        walk_s.ring.extend(ring.coords.iter().map(|c| wg.snap(*c)));
        let mark = walk_s.arena.travs.len();
        walk(&mut walk_s.ring, &wg, true, &mut walk_s.arena).map_err(|e| e.at(at))?;
        let ring_no = u32::try_from(ring_idx).map_err(|_| internal("more than 2^32 rings"))?;
        let arena = &mut walk_s.arena;
        let travs = arena.travs.get_mut(mark..).ok_or_else(|| internal("arena mark"))?;
        travs.sort_unstable_by_key(|t| (t.row, t.col, t.seq));
        for group in travs.chunk_by(|a, b| (a.row, a.col) == (b.row, b.col)) {
            if let Some(acc) = cell_record(group, &arena.coords, &wg, ring.role, ring_no, s).map_err(internal)? {
                s.acc.push(acc);
            }
        }
    }
    // The ring number makes the key unique, so the float sums keep one order everywhere.
    s.acc.sort_unstable_by_key(|a| (a.row, a.col, a.ring));
    sweep::emit(&s.acc, &wg, id, out);
    Ok(())
}

/// One ring's coverage and winding for one cell (controlledburn `walk_ring`).
fn cell_record(
    group: &[Trav],
    coords: &[Coord],
    wg: &WalkerGrid,
    role: RingRole,
    ring: u32,
    s: &mut CoverageScratch,
) -> Result<Option<CellAcc>, &'static str> {
    let Some(first) = group.first() else {
        return Ok(None);
    };
    let (r, c) = (first.row, first.col);
    if wg.row(r).is_none() {
        return Ok(None); // padding rows carry no winding for any grid row
    }
    s.valid.clear();
    s.valid.extend(group.iter().filter_map(|t| t.classify(coords).map(|v| (t.range(), v))));
    if s.valid.is_empty() {
        return Ok(None);
    }
    let bx = wg.cell_box(r, c);
    let frac = if wg.col(c).is_some() { to_f32(fraction_of(&bx, coords, s)?) } else { 0.0 };

    let y_mid = (bx.ymin + bx.ymax) / 2.0;
    let mut wind = 0;
    let mut crossed = false;
    for (range, v) in &s.valid {
        let Valid::Through { .. } = v else { continue }; // closed rings give no winding
        let Some(cs) = coords.get(range.clone()) else { continue };
        let (Some(a), Some(b)) = (cs.first(), cs.last()) else { continue };
        if cs.len() < 2 {
            continue;
        }
        // Half-open at y_mid: controlledburn fix 0efe32f.
        if (a.y >= y_mid && b.y < y_mid) || (a.y < y_mid && b.y >= y_mid) {
            crossed = true;
            wind += if a.y >= y_mid { -1 } else { 1 };
        }
    }
    if frac == 0.0 && !crossed {
        return Ok(None);
    }
    Ok(Some(CellAcc { row: r, col: c, ring, cov: role.sign_f32() * frac, wind: wind * role.sign_i32() }))
}

fn fraction_of(bx: &CellBox, coords: &[Coord], s: &mut CoverageScratch) -> Result<f64, &'static str> {
    let err = "traversal end is not on the cell boundary";
    match s.valid.as_slice() {
        [(r, Valid::ClosedInCell)] => Ok(closed_ring_fraction(bx, coords.get(r.clone()).ok_or(err)?)),
        [(r, Valid::Through { .. })] => analytical_fraction(bx, coords.get(r.clone()).ok_or(err)?).ok_or(err),
        many => {
            s.ranges.clear();
            s.ranges.extend(many.iter().map(|(r, _)| r.clone()));
            let area = bx.area();
            if area > 0.0 {
                Ok(left_hand_area(bx, coords, &s.ranges, &mut s.chains, &mut s.lha).ok_or(err)? / area)
            } else {
                Ok(0.0)
            }
        }
    }
}

use crate::coverage::fraction::CellClass;
use crate::grid::{Col, Row, Span};
use crate::output::Emit;

/// One merged cell of the controlledburn sweep loop: the run between cells, then the cell.
pub(crate) fn step(st: &mut SweepState, cell: MergedCell, n_cols: usize) -> [Option<LocalEmit>; 2] {
    let between = match st.prev {
        Some(p) if st.winding != 0 && cell.col.0 > p.0 + 1 => Some(LocalEmit::Run(LocalCol(p.0 + 1), cell.col)),
        _ => None,
    };
    let own = if (1..=n_cols).contains(&cell.col.0) {
        match CellClass::of(cell.cov) {
            CellClass::Edge(w) => Some(LocalEmit::Edge(cell.col, w)),
            CellClass::Full => Some(LocalEmit::Run(cell.col, LocalCol(cell.col.0 + 1))),
            CellClass::Empty => None,
        }
    } else {
        None
    };
    st.winding += cell.wind;
    st.prev = Some(cell.col);
    [between, own]
}

/// Sweeps each row of `acc` (sorted by row, col, ring) and writes global records.
pub(crate) fn emit(acc: &[CellAcc], wg: &WalkerGrid, id: GeomId, out: &mut BurnResult) {
    for row_cells in acc.chunk_by(|a, b| a.row == b.row) {
        let Some(row) = row_cells.first().and_then(|c| wg.row(c.row)) else { continue };
        row_cells
            .chunk_by(|a, b| a.col == b.col)
            .filter_map(|cs| {
                Some(MergedCell {
                    col: cs.first()?.col,
                    cov: cs.iter().fold(0.0, |s, c| s + c.cov),
                    wind: cs.iter().map(|c| c.wind).sum(),
                })
            })
            .scan(SweepState::default(), |st, c| Some(step(st, c, wg.n_cols())))
            .flatten()
            .flatten()
            .filter_map(|e| to_global(e, row, wg))
            .for_each(|e| out.push(id, e));
    }
}

fn to_global(e: LocalEmit, row: Row, wg: &WalkerGrid) -> Option<Emit> {
    match e {
        LocalEmit::Run(a, b) => {
            let (a, b) = (a.0.max(1), b.0.min(wg.n_cols() + 1));
            if a >= b {
                return None;
            }
            let start = wg.col(LocalCol(a))?;
            let last = wg.col(LocalCol(b - 1))?;
            Some(Emit::Run { row, cols: Span::from_parts(start, Col(last.0 + 1)) })
        }
        LocalEmit::Edge(c, w) => Some(Emit::Edge { row, col: wg.col(c)?, fraction: w }),
    }
}

/// One intercept of the controlledburn approx sweep. Left of centre is `x <= x_mid`.
pub(crate) fn step(st: &mut ApproxState, ix: &Icpt, grid: &Grid) -> Option<Span<Col>> {
    let wc = grid.cols();
    let (c0, c1) = (wc.start().0, wc.end().0);
    let col = match grid.col_of(ix.x) {
        Pos::Before => c0,
        Pos::After => c1 - 1,
        Pos::In(c) => c.0.clamp(c0, c1 - 1),
    };
    let x_mid = grid.lattice().x_mid(i64::from(col));
    let new = st.winding + ix.delta;
    let mut run = None;
    if ix.x <= x_mid {
        if st.winding != 0 && new == 0 {
            // Leave before the centre: close the run before this cell.
            if let Some(s) = st.run_start.take() {
                run = (s < col).then(|| Span::from_parts(Col(s), Col(col)));
            }
        } else if st.winding == 0 && new != 0 {
            st.run_start = Some(col); // enter before the centre: this cell is in
        }
    } else if st.winding != 0 && new == 0 {
        // Leave after the centre: include this cell.
        let s = st.run_start.take().unwrap_or(col);
        let e = (col + 1).min(c1);
        run = (s < e).then(|| Span::from_parts(Col(s), Col(e)));
    } else if st.winding == 0 && new != 0 {
        st.run_start = Some(col + 1); // enter after the centre: start after this cell
    }
    st.winding = new;
    run
}

/// From controlledburn `process_polygon_approx`
/// ([cpp/src/scanline.cpp](https://github.com/hypertidy/controlledburn/blob/1f8a25fd030ac6ec1aa2fbf2c69ee35df8c17558/cpp/src/scanline.cpp)),
/// on the lattice, all components in one sweep.
pub(crate) fn burn(
    input: &InputBuf,
    grid: &Grid,
    id: GeomId,
    icpt: &mut Vec<Icpt>,
    out: &mut BurnResult,
) -> Result<(), BurnError> {
    let Some(env) = input.envelope() else {
        return Ok(());
    };
    let l = *grid.lattice();
    let (wr, wc) = (grid.rows(), grid.cols());
    if env.xmax < l.x_edge(i64::from(wc.start().0)) || env.xmin > l.x_edge(i64::from(wc.end().0)) {
        return Ok(());
    }
    let row_lo = match grid.row_of(env.ymax) {
        Pos::Before => i64::from(wr.start().0),
        Pos::In(r) => i64::from(r.0).max(i64::from(wr.start().0)),
        Pos::After => return Ok(()),
    };
    let row_hi = match grid.row_of(env.ymin) {
        Pos::Before => return Ok(()),
        Pos::In(r) => i64::from(r.0).min(i64::from(wr.end().0) - 1),
        Pos::After => i64::from(wr.end().0) - 1,
    };
    if row_lo > row_hi {
        return Ok(());
    }

    icpt.clear();
    let mut seq = 0_u32;
    let (y0, dy) = (l.y0(), l.dy());
    for ring in input.rings() {
        let factor = ring.role.sign_i32(); // rings are CCW after normalization
        for w in ring.coords.windows(2) {
            let (p, q) = (w[0], w[1]);
            if p.y == q.y {
                continue; // horizontal edge
            }
            let (ya, yb) = if p.y < q.y { (p.y, q.y) } else { (q.y, p.y) };
            // Rows with ya < y_mid <= yb (top-inclusive, bottom-exclusive).
            let e_lo = ceil_clamped((y0 - yb) / dy - 0.5 - 1e-10, row_lo, row_hi + 1).max(row_lo);
            let e_hi = (ceil_clamped((y0 - ya) / dy - 0.5 - 1e-10, row_lo - 1, row_hi + 1) - 1).min(row_hi);
            if e_lo > e_hi {
                continue;
            }
            let inv = 1.0 / (q.y - p.y);
            // Sign from the edge endpoints: controlledburn fix 65af8d7.
            let delta = if q.y < p.y { -1 } else { 1 } * factor;
            for r in e_lo..=e_hi {
                let t = (l.y_mid(r) - p.y) * inv;
                let row = u32::try_from(r).map_err(|_| BurnError::Internal { id, detail: "approx row" })?;
                icpt.push(Icpt { row, x: p.x + t * (q.x - p.x), delta, seq });
                seq = seq.wrapping_add(1);
            }
        }
    }
    icpt.sort_unstable_by(|a, b| a.row.cmp(&b.row).then(a.x.total_cmp(&b.x)).then(a.seq.cmp(&b.seq)));

    let c1 = wc.end().0;
    for row_icpts in icpt.chunk_by(|a, b| a.row == b.row) {
        let Some(row) = row_icpts.first().map(|i| crate::grid::Row(i.row)) else { continue };
        let mut st = ApproxState::default();
        row_icpts
            .iter()
            .filter_map(|ix| step(&mut st, ix, grid))
            .for_each(|cols| out.push(id, Emit::Run { row, cols }));
        // The polygon goes past the right window edge.
        if st.winding != 0 {
            if let Some(s) = st.run_start.filter(|&s| s < c1) {
                out.push(id, Emit::Run { row, cols: Span::from_parts(Col(s), Col(c1)) });
            }
        }
    }
    Ok(())
}

#[expect(clippy::cast_possible_truncation, reason = "clamped to [lo, hi] before the cast")]
fn ceil_clamped(v: f64, lo: i64, hi: i64) -> i64 {
    v.ceil().clamp(to_f64(lo), to_f64(hi)) as i64
}

use crate::coverage::{fraction::to_f32, walk::walk};
use crate::error::At;
use crate::geom::walker_grid::WalkerGrid;
use crate::output::Emit;

/// From controlledburn `process_line`
/// ([cpp/src/scanline.cpp](https://github.com/hypertidy/controlledburn/blob/1f8a25fd030ac6ec1aa2fbf2c69ee35df8c17558/cpp/src/scanline.cpp)):
/// open walks, all traversals of a cell summed in visit order.
pub(crate) fn burn(
    input: &InputBuf,
    grid: &Grid,
    id: GeomId,
    s: &mut WalkScratch,
    out: &mut BurnResult,
) -> Result<(), BurnError> {
    let Some(env) = input.envelope() else {
        return Ok(());
    };
    // controlledburn walks the full grid; burnscars walks the window region.
    let Some(wg) = WalkerGrid::for_envelope(grid, &env) else {
        return Ok(());
    };
    s.arena.clear();
    for (part, line) in input.lines() {
        s.ring.clear();
        s.ring.extend(line.iter().map(|c| wg.snap(*c)));
        let at = At { id, part, ring: 0, vertex: 0 };
        walk(&mut s.ring, &wg, false, &mut s.arena).map_err(|e| e.at(at))?;
    }
    let arena = &mut s.arena;
    arena.travs.sort_unstable_by_key(|t| (t.row, t.col, t.seq));
    for group in arena.travs.chunk_by(|a, b| (a.row, a.col) == (b.row, b.col)) {
        let Some(first) = group.first() else { continue };
        let (Some(row), Some(col)) = (wg.row(first.row), wg.col(first.col)) else { continue };
        // Visit order, one running sum: the same order as the C++ loop.
        let len = group
            .iter()
            .filter_map(|t| arena.coords.get(t.range()))
            .flat_map(|cs| cs.windows(2))
            .fold(0.0, |sum, w| sum + seg_len(w));
        if len > 0.0 {
            out.push(id, Emit::Line { row, col, length: to_f32(len) });
        }
    }
    Ok(())
}

fn seg_len(w: &[crate::geom::coord::Coord]) -> f64 {
    match w {
        [a, b] => {
            let (sx, sy) = (b.x - a.x, b.y - a.y);
            (sx * sx + sy * sy).sqrt() // controlledburn uses sqrt, not hypot
        }
        _ => 0.0,
    }
}

/// Minimal CSV reader: comma separator, double-quoted fields, no escaped quotes.
pub fn read_csv(text: &str) -> Vec<Vec<String>> {
    text.lines()
        .filter(|l| !l.trim().is_empty())
        .map(|line| {
            let mut fields = Vec::new();
            let mut cur = String::new();
            let mut quoted = false;
            for ch in line.chars() {
                match (ch, quoted) {
                    ('"', _) => quoted = !quoted,
                    (',', false) => fields.push(std::mem::take(&mut cur)),
                    _ => cur.push(ch),
                }
            }
            fields.push(cur);
            fields
        })
        .collect()
}

pub fn hex(s: &str) -> Vec<u8> {
    (0..s.len() / 2).filter_map(|i| u8::from_str_radix(s.get(2 * i..2 * i + 2)?, 16).ok()).collect()
}

pub fn known_diffs(table: &str) -> Vec<(String, String)> {
    let text = std::fs::read_to_string(concat!(env!("CARGO_MANIFEST_DIR"), "/oracle/known_diffs.toml")).unwrap_or_default();
    let doc: toml::Table = text.parse().unwrap_or_default();
    doc.get("diff")
        .and_then(toml::Value::as_array)
        .into_iter()
        .flatten()
        .filter_map(|d| {
            let t = d.get("table")?.as_str()?;
            let case = d.get("case")?.as_str()?.to_owned();
            let reason = d.get("reason")?.as_str()?.to_owned();
            assert!(!reason.trim().is_empty(), "known diff {case} has no reason");
            (t == table).then_some((case, reason))
        })
        .collect()
}

//! Partition equality (spec: Output order and determinism): feature-split and tile-split
//! burns give the same expanded form as the full burn, bit for bit.

mod common;

use burnscars::{BurnResult, Burner, Col, GeomId, Grid, Lattice, Mode, Row, Span};
use common::{expanded, ls};
use geo_types::{Geometry, LineString, MultiPoint, Point, Polygon, coord};

/// A star polygon around (cx, cy); some vertices snap to the lattice (x0 = 0, y0 = 32).
/// The filter keeps it simple: angles about the centre strictly increase and every
/// angular gap is < pi, so the polygon is valid (spec: valid input only).
fn star_polygon(dx: f64, dy: f64) -> impl Strategy<Value = Polygon<f64>> {
    (4.0..28.0_f64, 4.0..28.0_f64, prop::collection::vec((1.0..6.0_f64, any::<bool>()), 3..24))
        .prop_map(move |(cx, cy, radii)| {
            let n = radii.len();
            let pts: Vec<(f64, f64)> = radii
                .iter()
                .enumerate()
                .map(|(i, &(r, snap))| {
                    let a = std::f64::consts::TAU * (i as f64) / (n as f64);
                    let (x, y) = (cx + r * a.cos(), cy + r * a.sin());
                    if snap { ((x / dx).round() * dx, 32.0 - ((32.0 - y) / dy).round() * dy) } else { (x, y) }
                })
                .collect();
            (cx, cy, pts)
        })
        .prop_filter("simple star", |(cx, cy, pts)| {
            let ang: Vec<f64> = pts.iter().map(|&(x, y)| (y - cy).atan2(x - cx).rem_euclid(std::f64::consts::TAU)).collect();
            let increasing = ang.windows(2).all(|w| w[1] > w[0]);
            let gaps = ang.windows(2).map(|w| w[1] - w[0]).chain(std::iter::once(ang[0] + std::f64::consts::TAU - ang[ang.len() - 1]));
            increasing && gaps.into_iter().all(|g| g < std::f64::consts::PI - 1e-9)
        })
        .prop_map(|(_, _, pts)| Polygon::new(LineString::from(pts), vec![]))
}

fn polyline() -> impl Strategy<Value = LineString<f64>> {
    prop::collection::vec((0.0..32.0_f64, 0.0..32.0_f64), 2..8).prop_map(|v| ls(&v))
}

fn chunks(n: u32, size: u32) -> Vec<(u32, u32)> {
    (0..n).step_by(size as usize).map(|s| (s, (s + size).min(n))).collect()
}

fn burn_all(mode: Mode, g: &Grid, geoms: &[Geometry<f64>]) -> BurnResult {
    let items = geoms.iter().enumerate().map(|(i, x)| (GeomId(i as u32), x));
    Burner::new(mode).burn(g, items).expect("burn")
}

/// Lattice resolution first, so the polygons can snap to that lattice.
fn case() -> impl Strategy<Value = (f64, f64, Vec<Polygon<f64>>)> {
    (0.3..2.0_f64, 0.3..2.0_f64).prop_flat_map(|(dx, dy)| {
        (Just(dx), Just(dy), prop::collection::vec(star_polygon(dx, dy), 1..4))
    })
}

    #[test]
    fn tiles_and_feature_splits_equal_the_full_burn(
        ncol in 1_u32..40, nrow in 1_u32..40, (dx, dy, polys) in case(),
        lines in prop::collection::vec(polyline(), 0..3),
        pts in prop::collection::vec((0.0..32.0_f64, 0.0..32.0_f64), 0..6),
        rchunk in 1_u32..12, cchunk in 1_u32..12, split in 0_usize..8,
    ) {
        let lat = Lattice::new(0.0, 32.0, dx, dy).expect("lattice");
        let g = Grid::new(lat, Span::new(Row(0), Row(nrow)).expect("r"), Span::new(Col(0), Col(ncol)).expect("c")).expect("grid");
        let mut geoms: Vec<Geometry<f64>> = polys.into_iter().map(Geometry::Polygon).collect();
        geoms.extend(lines.into_iter().map(Geometry::LineString));
        geoms.push(Geometry::MultiPoint(MultiPoint::new(pts.iter().map(|&(x, y)| Point::new(x, y)).collect())));

        for mode in [Mode::Coverage, Mode::Approx] {
            let full = expanded(&burn_all(mode, &g, &geoms));

            // Feature split: two workers, ids kept, results concatenated.
            let k = split.min(geoms.len());
            let mut b = Burner::new(mode);
            let mut out = BurnResult::default();
            let items = geoms.iter().enumerate().map(|(i, x)| (GeomId(i as u32), x));
            b.burn_into(&g, items.clone().take(k), &mut out).expect("a");
            Burner::new(mode).burn_into(&g, items.skip(k), &mut out).expect("b");
            prop_assert_eq!(&expanded(&out), &full);

            // Tile split: every chunk made with window(), outputs merged.
            let mut tiled = std::collections::BTreeMap::new();
            for (r0, r1) in chunks(nrow, rchunk) {
                for (c0, c1) in chunks(ncol, cchunk) {
                    let w = g.window(Span::new(Row(r0), Row(r1)).expect("r"), Span::new(Col(c0), Col(c1)).expect("c")).expect("w");
                    for (key, mut v) in expanded(&burn_all(mode, &w, &geoms)) {
                        tiled.entry(key).or_insert_with(Vec::new).append(&mut v);
                    }
                }
            }
            for v in tiled.values_mut() { v.sort_unstable(); }
            prop_assert_eq!(&tiled, &full);
        }
    }

"""Oracle fixtures for burnscars.

Coverage oracle: exactextract (cell_id, coverage). Approx oracle: GDAL rasterize through
rasterio (centre rule). GEOS (shapely) is used only as a black box: is_valid, area, WKB.
"""

import argparse
import math
from pathlib import Path

import numpy as np
import rasterio.features
import rasterio.transform
import shapely
from exactextract import exact_extract
from exactextract.raster import NumPyRasterSource


def read_corpus(path):
    cases = []
    for line in Path(path).read_text().splitlines():
        if not line.strip() or line.startswith("#"):
            continue
        name, wkt, grid = line.split("|")
        xmin, ymin, xmax, ymax, ncol, nrow = grid.split()
        cases.append((name, shapely.from_wkt(wkt), (float(xmin), float(ymin), float(xmax), float(ymax), int(ncol), int(nrow))))
    return cases


def random_cases(seed=20261014, n=40):
    rng = np.random.default_rng(seed)
    out = []
    for i in range(n):
        ncol, nrow = int(rng.integers(5, 60)), int(rng.integers(5, 60))
        dx, dy = 10.0 / ncol, 10.0 / nrow
        k = int(rng.integers(3, 30))
        cx, cy = rng.uniform(2, 8, 2)
        ang = np.sort(rng.uniform(0, 2 * math.pi, k))
        rad = rng.uniform(0.3, 4.0, k)
        xs, ys = cx + rad * np.cos(ang), cy + rad * np.sin(ang)
        if i % 3 == 0:  # vertices on the lattice
            xs, ys = np.round(xs / dx) * dx, np.round(ys / dy) * dy
        if i % 3 == 1:  # vertices a few ulp from the lattice
            xs = np.nextafter(np.round(xs / dx) * dx, np.inf)
        g = shapely.Polygon(np.column_stack([xs, ys]))
        if g.is_valid and g.area > 0:
            out.append((f"random_{i}", g, (0.0, 0.0, 10.0, 10.0, ncol, nrow)))
    return out


def coverage(g, grid):
    xmin, ymin, xmax, ymax, ncol, nrow = grid
    src = NumPyRasterSource(np.zeros((nrow, ncol)), xmin, ymin, xmax, ymax)
    feats = [{"type": "Feature", "properties": {}, "geometry": shapely.geometry.mapping(g)}]
    res = exact_extract(src, feats, ["cell_id", "coverage"], output="geojson")
    props = res[0]["properties"]
    cells = [(int(c) // ncol, int(c) % ncol, float(f)) for c, f in zip(props["cell_id"], props["coverage"])]
    # Self-check of the cell_id meaning: the sum of coverage is the clipped area.
    cell_area = (xmax - xmin) / ncol * (ymax - ymin) / nrow
    want = g.intersection(shapely.box(xmin, ymin, xmax, ymax)).area
    got = sum(f for _, _, f in cells) * cell_area
    assert abs(got - want) <= 1e-6 * max(want, 1.0), (got, want)
    return cells


def approx(g, grid):
    xmin, ymin, xmax, ymax, ncol, nrow = grid
    t = rasterio.transform.from_bounds(xmin, ymin, xmax, ymax, ncol, nrow)
    a = rasterio.features.rasterize([(g, 1)], out_shape=(nrow, ncol), transform=t, all_touched=False, fill=0, dtype="uint8")
    return [(int(r), int(c)) for r, c in zip(*np.nonzero(a))]


def main():
    p = argparse.ArgumentParser()
    p.add_argument("--out", required=True)
    p.add_argument("--corpus", default=str(Path(__file__).with_name("corpus.wkt")))
    p.add_argument("--no-random", action="store_true")
    a = p.parse_args()
    cases = read_corpus(a.corpus) + ([] if a.no_random else random_cases())
    out = Path(a.out)
    out.mkdir(parents=True, exist_ok=True)
    with open(out / "cases.csv", "w") as fc, open(out / "coverage.csv", "w") as fv, open(out / "approx.csv", "w") as fa:
        fc.write("case,wkb_hex,xmin,ymin,xmax,ymax,ncol,nrow\n")
        fv.write("case,row,col,fraction\n")
        fa.write("case,row,col\n")
        for name, g, grid in cases:
            assert g.is_valid, name
            fc.write(f"{name},{shapely.to_wkb(g, hex=True)},{','.join(repr(v) for v in grid)}\n")
            for r, c, f in coverage(g, grid):
                if f > 0:
                    fv.write(f"{name},{r},{c},{f:.9g}\n")
            for r, c in approx(g, grid):
                fa.write(f"{name},{r},{c}\n")


if __name__ == "__main__":
    main()

fn grid_of(r: &[String]) -> Grid {
    let f = |i: usize| r[i].parse::<f64>().expect("grid value");
    Grid::from_extent(f(2), f(3), f(4), f(5), r[6].parse().expect("ncol"), r[7].parse().expect("nrow")).expect("grid")

fn burn(case: &[String], mode: Mode) -> BurnResult {
    let bytes = hex(&case[1]);
    let g = wkb::reader::read_wkb(&bytes).expect("wkb");
    Burner::new(mode).burn(&grid_of(case), [(GeomId(0), &g)]).expect("burn")

/// Per-cell fraction, runs as 1, cells below TOL removed.
fn cells(r: &BurnResult) -> BTreeMap<(u32, u32), f64> {
    let mut m = BTreeMap::new();
    for x in r.runs.iter() {
        for c in x.cols.range() {
            m.insert((x.row.0, c), 1.0);
        }
    }
    for e in r.edges.iter() {
        m.insert((e.row.0, e.col.0), f64::from(e.fraction));
    }
    m.retain(|_, f| *f >= TOL);
    m
}

fn oracle_cells(rows: &[Vec<String>], case: &str) -> BTreeMap<(u32, u32), f64> {
    rows.iter()
        .filter(|r| r[0] == case)
        .map(|r| ((r[1].parse().expect("row"), r[2].parse().expect("col")), r.get(3).map_or(1.0, |f| f.parse().expect("f"))))
        .filter(|(_, f)| *f >= TOL)
        .collect()
}

fn compare(table: &str, mode: Mode, oracle: &str) {
    let skip = known_diffs(table);
    let cases = read_csv(CASES);
    let rows = read_csv(oracle);
    let mut failures = Vec::new();
    for case in &cases[1..] {
        if skip.iter().any(|(c, _)| *c == case[0]) {
            continue;
        }
        let got = cells(&burn(case, mode));
        let want = oracle_cells(&rows[1..], &case[0]);
        let keys_equal = got.keys().eq(want.keys());
        let values_close = got.iter().zip(&want).all(|((_, a), (_, b))| (a - b).abs() <= TOL);
        if !(keys_equal && values_close) {
            failures.push(case[0].clone());
        }
    }
    assert!(failures.is_empty(), "{table} differs from the oracle for: {failures:?}");
}

#+begin_src rust
//! Steady state makes no allocation (spec: Storage, O6). One test per binary, so no
//! other test changes the counter.
#![expect(unsafe_code, reason = "test-only counting allocator")]

mod common;

use std::alloc::{GlobalAlloc, Layout, System};
use std::sync::atomic::{AtomicUsize, Ordering};

use burnscars::{BurnResult, Burner, GeomId, Mode};
use common::{grid, ls, poly};
use geo_types::{Geometry, MultiPoint, Point};

struct Counting;
static ALLOCS: AtomicUsize = AtomicUsize::new(0);

// SAFETY: forwards every call to `System` unchanged; only counts.
unsafe impl GlobalAlloc for Counting {
    unsafe fn alloc(&self, l: Layout) -> *mut u8 {
        ALLOCS.fetch_add(1, Ordering::Relaxed);
        // SAFETY: same contract as the caller's.
        unsafe { System.alloc(l) }
    }
    unsafe fn dealloc(&self, p: *mut u8, l: Layout) {
        // SAFETY: same contract as the caller's.
        unsafe { System.dealloc(p, l) }
    }
    unsafe fn realloc(&self, p: *mut u8, l: Layout, n: usize) -> *mut u8 {
        ALLOCS.fetch_add(1, Ordering::Relaxed);
        // SAFETY: same contract as the caller's.
        unsafe { System.realloc(p, l, n) }
    }
}

#[global_allocator]
static A: Counting = Counting;

#[test]
fn second_burn_makes_no_allocation() {
    let g = grid(0.0, 0.0, 10.0, 10.0, 50, 50);
    let geoms: Vec<Geometry<f64>> = vec![
        Geometry::Polygon(poly(
            &[(1.3, 1.3), (8.7, 2.1), (7.9, 8.4), (2.2, 7.7), (1.3, 1.3)],
            &[&[(3.0, 3.0), (5.0, 3.1), (4.2, 5.0), (3.0, 3.0)]],
        )),
        Geometry::LineString(ls(&[(0.5, 0.5), (9.5, 7.5), (2.0, 9.0)])),
        Geometry::MultiPoint(MultiPoint::new(vec![Point::new(1.0, 1.0), Point::new(9.0, 9.0)])),
    ];
    for mode in [Mode::Coverage, Mode::Approx] {
        let mut b = Burner::new(mode);
        let mut out = BurnResult::default();
        let items = || geoms.iter().enumerate().map(|(i, x)| (GeomId(u32::try_from(i).unwrap_or(0)), x));
        b.burn_into(&g, items(), &mut out).expect("warm-up");
        out.clear();
        let before = ALLOCS.load(Ordering::Relaxed);
        b.burn_into(&g, items(), &mut out).expect("burn");
        let after = ALLOCS.load(Ordering::Relaxed);
        assert_eq!(after - before, 0, "{mode:?}");
    }
}

//! Benchmarks (spec: Benchmarks). Synthetic cases, both modes.

use burnscars::{Burner, GeomId, Grid, Mode};
use criterion::{Criterion, criterion_group, criterion_main};
use geo_types::{LineString, Polygon, coord};
use std::hint::black_box;

fn circle(n: usize, cx: f64, cy: f64, r: f64) -> Polygon<f64> {
    let pts: LineString<f64> = (0..n)
        .map(|i| {
            let a = std::f64::consts::TAU * (i as f64) / (n as f64);
            coord! { x: cx + r * a.cos(), y: cy + r * a.sin() }
        })
        .collect();
    Polygon::new(pts, vec![])
}

fn bench(c: &mut Criterion) {
    let big = circle(1_000_000, 50.0, 50.0, 40.0);
    let small: Vec<Polygon<f64>> = (0..10_000)
        .map(|i| circle(16, f64::from(i % 100) + 0.5, f64::from(i / 100) + 0.5, 0.4))
        .collect();
    for side in [100_u32, 1_000, 10_000, 31_623] {
        let g = Grid::from_extent(0.0, 0.0, 100.0, 100.0, side, side).expect("grid");
        for mode in [Mode::Coverage, Mode::Approx] {
            c.bench_function(&format!("circle_1e6/{side}/{mode:?}"), |b| {
                let mut burner = Burner::new(mode);
                b.iter(|| black_box(burner.burn(&g, [(GeomId(0), &big)]).expect("burn")));
            });
            c.bench_function(&format!("small_1e4/{side}/{mode:?}"), |b| {
                let mut burner = Burner::new(mode);
                b.iter(|| {
                    let items = small.iter().enumerate().map(|(i, p)| (GeomId(i as u32), p));
                    black_box(burner.burn(&g, items).expect("burn"))
                });
            });
        }
    }
}

criterion_group!(benches, bench);
criterion_main!(benches);
